# Recursion Practice Assignment (Java)

This repository contains 26 separate Java solutions for the Recursion Practice Assignment.

## How to run a solution

Open a terminal in this folder and run, for example:

```bash
javac Q1_Print1ToN.java
java Q1_Print1ToN
```

Enter the input shown in the assignment PDF. Each Java file contains its own `main` method and uses `Scanner` for input.

## Files

- Q1–Q6: Basic recursion
- Q7–Q21: String and number recursion
- Q22–Q26: Recursive array operations and searching
